# ログイン背景

`crayon-background.webp` は利用者が2026-11-07に提供した、ロゴ・入力フォームを含まない画像A（864×1536）のWebP最適化版。短い3本の飾り線を除いた提供版を使用し、絵の追加・再生成・色変更はしていない。画像Bは配置の参考のみで、アプリに含めていない。

上420pxの装飾はロゴに重ならない右上144px幅へ等比配置する。CSSのborder-imageで下536pxは元の縦横比で描画し、絵のない中央の紙部分だけを画面高に合わせる。元の左上のパンをロゴの背後に重ねず、上の装飾はすべて右上へまとめて表示する。パン・植物・クレヨンを伸ばしたり、画面端で切り落とすcover表示にはしない。ロゴPNG2点は既存ファイルをそのまま使用する。rootにlogin-headerがある間だけ背景を適用し、認証後の業務画面には適用しない。
