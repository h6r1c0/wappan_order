## 継続する実務 UI・回帰基準（2026-10-23）

### 全工程の共通ルール

- 工程ごとの主色は注文・発注＝緑、販売＝青、納品・精算＝オレンジ、集金＝赤みのあるピンク。危険・成功・無効の意味色は工程色で上書きしない。主操作、選択中、補助リンク、見出しのアクセントを共通の工程変数から供給する。
- 大工程は番号・面色・太い左線、小項目は細い左線と控えめな見出し、詳細は展開時だけ表示する。集金一覧の名前と金額、商品一覧の商品名と残数が操作ボタンより先に読める配置を守る。主操作も最小44px程度の押せる領域を残す。
- 警告は「今なお未解決の作業」を表す。案内済み金額との差が保存済みの追加請求で説明できれば、過去の案内額を履歴として残し、未解決警告にしない。印刷不可の理由は印刷ボタンを押す前に示し、例外帳票なら未確定と記す。
- 現金受取と充当先の判断を分ける。複数の請求に対する一部受取は、金額だけで古い順へ自動充当しない。総未収とは別に「充当先未確認」を表示する。今回分・過去分・混合の各金額を確認し、既存受取は原本を維持して別の充当履歴を一件記録する。
- 注文、納品、販売先割当、おやつ、集計、設定の変更時も同種の操作部品・見出し・不要な説明を横断して点検する。密度・通常操作数・例外操作・保存後の移動を変更前後で比べる。

- 通常の操作を最短にする。集金は名前・予定額・「全額受取」を同じ行に置き、保存は1タップ。例外、内訳、訂正だけ行を開く。確認だけで受取を作らず、保存後に次の人の詳細を勝手に開かない。
- 表示密度と視認性を同時に測る。今回の同じ12人・375pxの検証データでは、通常の行は従前134pxから51px、初期画面の見える人数は約3人から約11人。320 / 375 / 430pxとPCで長い名前、高額、未確定、0円、完了済み、部分受取も確認する。名前・金額・押す場所が混ざったり横にはみ出したりしないこと。
- 未受取・請求未確定・差額調査中を作業一覧に残し、受取済みと集金不要は折りたたむ。過去不足、預かり、既知の請求差額だけ短い補足を表示する。価格が不明な商品を0円で精算しない。
- 商品別の販売先割当と履歴は同じ一覧から操作し、購入者から複数商品を扱う入口も残す。工程移動時の未保存入力を保護し、保存後は一覧へ戻す。元の取込メモと訂正履歴はデータに残し、通常画面では取込時の開発判断を表示しない。
- 注文回の価格スナップショット、納品数量、欠品、販売用在庫、おやつ原価、集金と繰越、年度集計除外を一連の操作で確認する。10月の残務と11月の発注を併行させ、マスター価格更新や再編集で旧価格が変わらないことを検証する。
- 既知の佐々木・西尾・堀・余語に加え、空・一部入力・全完了・再読込・連続保存・競合・訂正・価格未設定・長文・高額を組み合わせる。操作数、重複表示、保存後の行き先も探索的に確認し、見つけた後退は回帰テストへ残す。
- 本番データを検証のために変更しない。着手前にリビジョンとJSONの復旧用コピーを取り、公開後に件数・識別子・内容のハッシュを再照合する。公開版の認証後実操作が確認できない場合、その範囲を明示する。

## 今後の変更に適用するUX基準

上の数値・完了チェックは過去の検証記録。新しい画面では、その時点の同じデータ・同じ幅で比較して判断する。

1. 利用者が達成する通常業務を先に書き出す。アプリが保持する商品、数量、価格、請求先を再入力させず、通常操作を最短に、例外は必要になったときだけ開く。重要な本人判断（現金受取・充当先・未確定値）は勝手に確定しない。
2. 工程の主色は注文・発注＝緑、販売＝青、納品・精算＝オレンジ、集金＝ピンク。共通トークンから主操作・選択・見出しに展開し、警告・危険・成功・無効の意味色を上書きしない。状態は色だけで示さない。
3. 大工程は番号と面・強い境界、小項目は抑えたアクセント、詳細は必要時に開く。名前・金額または商品・残数を操作部品より先に読めるようにする。塗りつぶしボタンを乱用せず、補助操作は控えめにする。見た目の小ささと押せる領域を分けて考える。
4. 重複した金額・説明、開発時の取込判断メモ、不要な0個や完了済みの詳細を通常画面に並べない。監査原本は保存し、表示層で必要な業務情報に絞る。入力中の値と保存後の次の操作を保護する。
5. 320/375/430pxとPCで長い名前、高額、0円、未確定、空・途中・完了、エラー時を確認する。行高、スクロール、タップ数、遷移数、視認性、誤操作、保存結果を**変更前後で**比較し、改善しない変更は再設計する。

新しい指摘は同種の部品・他工程へ調査を広げる。変更範囲は根拠のある問題に限る。実務・会計・データ保全の検証は [開発・検証手順](DEVELOPMENT_CHECKS.md) に従う。

### 色鉛筆素材の限定採用（2026-10-24）

Googleドライブの `wappan_pencil_final_review.html` に埋め込まれた8枚のPNGを `src/assets/pencil/` に取り出した。01注文は緑、02発注は青、03納品・精算はオレンジ、04集金は赤とし、非選択でも工程の文字色を残す。薄い筆跡は選択中の工程と注文用途、濃い筆跡は工程内の主要保存操作だけで使う。背景は黄みの少ないオフホワイト。状態色は工程色と別の意味を保つ。

原本の囲み・下線・フォントと細かい赤色は採用確定ではない。追加の全面装飾より、実画面での文字、余白、タップ領域、長い名称、金額の可読性を優先する。素材を変える場合は原本と同じ条件で比較し、本人の美的判断が必要な変更は公開単位を分ける。
