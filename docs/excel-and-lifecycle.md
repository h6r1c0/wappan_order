# Excel取込・商品候補の扱い

Excelを選ぶとシート内容から月次パン／定番焼き菓子を判定し、商品名、税込価格、販売価格、商品区分を一覧表示します。商品カードを開くと修正・除外できます。登録は確認ボタンを押すまで行いません。未知の形式だけ詳細設定で列と開始行を指定します。

- 税込価格はセルの整数値、またはExcelが実際に表示する整数価格を使用します。表示の根拠がない小数は自動確定しません。
- 月次パンは左右の表と途中の税込見出しの変更を追跡します。スライス価格は別候補です。個数入りの商品は単品と混同せず、内容量を商品名に残します。
- 明示的常設定番（ツイストドーナツ、ミルクスティック／ミルクスティックパン、黒糖ブレッド）を最優先します。登録済みの個別販売価格を引き継ぎます。
- 結合セルを含む「今月のおすすめパン／菓子」の区画は今回限りです。その他の通常欄と定番焼き菓子は定番です。「夏期」というタイトルや季節の注意書きだけで期間商品にはしません。
- 今回限りは選択した注文回にだけ追加します。取込画面から新しい納品日の注文回も作れます。期間商品は開始日・終了日で候補を絞ります。
- 作成済み注文回の商品名・価格・数量はマスター更新の影響を受けません。価格修正が必要な既存回は「この回の商品」で明示的に変更します。

## 園内販売の未確認情報

仕入単価が不明なら空欄で保持し、利益は未確定です。後から単価を入力すると、それまで未確定だった販売記録の原価にも反映します。

「売れたことだけ確認済み」は残数と売上だけを更新し、購入者請求・入金済みには含めません。支払方法を確認できたら元の記録を取り消し、正しい購入者または即時入金として記録します。取消履歴は保存されます。

## 検証

`npm test` は価格・区分・数量・請求・利益・年度除外と、PGliteで全migration／RLS／競合・在庫検証を実行します。

`npx playwright test` は375px中心、320／430pxも確認するブラウザーテストです。テストの通信は隔離した共有バックエンドを使用し、本番DBへダミーを作りません。

実資料は公開リポジトリに含めません。ローカルで `WAPPAN_EXCEL_DIR` を資料フォルダーに指定すると添付Excelの再テストを実行します。私的な照合スクリプトがある環境のみ `WAPPAN_RECON=1` で資料復元データの画面テストも実行できます。`.reconciliation-*` はgit対象外です。

追加migration: `20260915113650_product_lifecycle_pending_sales.sql`。係の認証・RLS・更新権限を緩和せず、原価不明／販売先未確認の整合性チェックと商品区分の検証を追加しています。
